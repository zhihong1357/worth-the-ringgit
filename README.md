# Worth the Ringgit · 最优持仓成本计算器

手机、电脑、汽车、包、手表这类会贬值的自用资产，怎么买、用多久再卖，年均成本最低？这个工具先问你的条件，再只在你能走的买法里找最优解。

- 纯静态网页，无后端、无依赖、不上传任何数据；你的条件只存在自己浏览器里。
- 数据按马来西亚市场与 2026 课税年规则，金额单位 RM。
- 这是测算工具，不是财务或税务建议。

## 怎么用

在线使用：仓库设置里开启 GitHub Pages（Settings → Pages → Deploy from a branch → `main` / root）后，访问 `https://zhihong1357.github.io/worth-the-ringgit/`。

本地使用：下载仓库，直接用浏览器打开 `index.html`。

三步：

1. **你的条件（全部可选）**：有没有信用卡、是哪类卡、能不能 0% 分期；个人应课税收入区间；有没有公司；接不接受二手。
2. **想买的资产**：选类别，填新品标价。
3. **看结论**：每种可行买法的最优策略、年均成本、每小时成本，以及残值波动下结论是否稳健。

## 模型

```
年均成本 = 净成本现值 × i ÷ (1 − (1 + i)^−n)
净成本现值 = 买入价 − 信用卡回扣 − 0% 分期的利息价值
           + 运行维护 + 一次性翻修 − 卖出净额 − 税盾      （全部按资金成本 i 折现）
```

工具会枚举“买入机龄 × 持有年数”的每一种组合，再乘以你能走的每条购买路径：

| 路径 | 出现条件 | 计入的好处 |
|---|---|---|
| 个人付现 | 总是可行 | 个人生活方式减免（仅手机、电脑，全新，需提供税率） |
| 个人刷卡一次付清 | 有信用卡且有回报 | 回扣或积分，受每月封顶限制 |
| 个人刷卡 0% 分期 | 卡支持分期 | 分期的利息价值；分期交易默认没有回扣 |
| 公司买入 | 有公司，且资产是手机、电脑或车 | 资本津贴税盾；持有不足两年按 0 计 |

几条内置规则：

- 现金流不等于成本。分期只改变付款时间，价值只有利息。
- 二手私人交易不能刷卡，也没有可用于减免的发票。
- 公司买入的资产属于公司，卖出所得归公司；两年内处置，资本津贴被追回。
- 包和手表不是经营资产，没有公司路径。
- 稳健性检验：把保值曲线按历史波动幅度上下浮动，看最优解是否改变。

## 文件

| 文件 | 内容 |
|---|---|
| `data.js` | 保值曲线、信用卡类型、税务规则。**改数据只改这里** |
| `engine.js` | 计算引擎，纯函数，浏览器和 Node 通用 |
| `app.js`、`index.html`、`style.css` | 页面 |
| `test.js` | 引擎测试，`node test.js` |
| `DATA.md` | 每个数字的来源与可信度 |

## 参与贡献

最需要的是**马来西亚本地的实际二手成交价**。默认曲线多数来自海外回收商数据，只有第一年和少数几个点有来源，其余是推算。

提交数据时请写明：型号与配置、新品标价、机龄、成交价、平台、日期。改 `data.js` 的曲线并在 `DATA.md` 补上来源，跑通 `node test.js` 后提 PR。

也欢迎：新增资产类别、其他国家的税务规则、英文和马来文界面。
